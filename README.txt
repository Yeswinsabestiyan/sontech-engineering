SONTECH ENGINEERING WEBSITE
===========================
This is a static website. No backend, database or server code is needed.

FILES
  index.html   page content
  css/style.css  all styling
  js/main.js   scroll animations and photo lightbox
  images/      all photos (replace a file with the same name to change a photo)

HOW TO PUBLISH (pick one)
1. Netlify Drop (easiest, free): go to app.netlify.com/drop and drag the whole
   sontech-website folder in. You get a live link in seconds.
2. GitHub Pages (free): upload these files to a GitHub repo, then Settings > Pages.
3. Hosting with cPanel (GoDaddy, Hostinger etc): upload everything inside this
   folder to public_html using File Manager. index.html must be at the top level.

CUSTOM DOMAIN
Buy a domain (for example sontechengineering.in) and connect it in your host's
domain settings.
